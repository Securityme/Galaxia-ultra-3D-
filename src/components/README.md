# src/components • Frosted Glass UI Components

Composants d'interface utilisateur en verre dépoli Tailwind CSS (GALAXIA Ultra).

## Fichiers & Responsabilités

| Fichier | Rôle unique |
| :--- | :--- |
| `TerrariumMount.tsx` | Composant de montage WebGL Three.js isolé |
| `GlassPanel.tsx` | Panneau réutilisable en verre dépoli avec bordure hairline |
| `HudBar.tsx` | Barre supérieure : télémétrie, cycle céleste, bouton Nouvel Événement |
| `CameraControls.tsx` | Contrôles flottants de caméra (Orbite 360°, Vue Plateau, Zoom) |
| `EventDialog.tsx` | Fenêtre d'événement narratif généré par LLM avec choix d'actions |
| `EventJournalModal.tsx` | Modal affichant l'historique complet des chroniques et décisions |
| `SectorPresetsModal.tsx` | Sélecteur visuel des 4 secteurs célestes et biomes |
| `WorldSettingsModal.tsx` | Réglages de relief, de graine déterministe et d'heure planétaire |
| `NpcInspectorModal.tsx` | Fiche d'inspection glass-panel pour les pionniers sélectionnés |
| `BuildingInspectorModal.tsx` | Fiche d'inspection glass-panel pour les structures sélectionnées |
